상태: **사용자 위임으로 확정(2026-10-29)**. 사용자: "필요한 그림은 API로 알아서". 견본 판정도 이 문서 기준으로 메인 세션이 한다.

| 칸 | 정한 것 |
|---|---|
| 한 줄 콘셉트 | 1910~60년대 지질학 연구실의 낡은 세계 지도. 바다는 차분한 남색 종이, 땅은 손으로 칠한 수채 지도처럼 대륙마다 다른 흐린 색. |
| 팔레트 | 16색 이내. `palette.json`과 같다(아래 표). 대륙 색 8개는 퍼즐에서 대륙을 구별하는 데 쓰므로 바꾸지 않는다. |
| 픽셀 밀도 | 가상 화면 480×360에서 1픽셀 = 1도트. 대륙·배경·초상·창 모두 같은 밀도. 초상(64×64)만 세밀하게 그리지 않는다. |
| 외곽선 | 대륙: 1도트, 땅 색보다 두 단계 어두운 색(`ink`). 초상·인물: 1도트 `ink`. 창 테두리: 2도트 `paper` + 안쪽 1도트 `slate`. 검은 외곽선은 쓰지 않는다. |
| 빛과 그림자 | 왼쪽 위에서 오는 빛. 2단계(바탕색, 한 단계 어두운 색)만. 대륙은 해안 안쪽 1도트 밝은 띠를 둘 수 있다. |
| 초상 | 64×64, 가슴 위 정면에서 살짝 왼쪽을 본 모습. 가상 조수 한별만 그린다. 베게너는 초상을 그리지 않는다(사진 저작권 불확실, `sources.md` W-PORTRAIT). |
| UI 창 | 바탕 `night`(#121a28), 테두리 `paper`(#e8dfc6), 안쪽 선 `slate`(#4b5870), 글자 `paper2`(#f4ecd8), 이름 `gold`(#ffd23f), 표시 `mist`(#9aa6b8). 지금 코드의 색과 같다. |
| 무늬 층 | 화석 띠·빙하 화살표·산맥 선은 코드가 근거 좌표(`patterns.json`)로 그린다. 생성 그림으로 바꾸지 않는다(위치가 사실이어서). |
| 하지 않는 것 | 그라데이션, 반투명, 중간색 외곽선(안티에일리어싱), 사진처럼 그린 질감, 상업 게임(포켓몬스터 등)의 그림·글꼴을 닮게 하기, 실존 인물 희화화. |

## 만들 그림과 순서 (견본 → 판정 → 대량)

1. **견본(5장, 호출 약 5~8번)**: 남아메리카·아프리카 대륙 질감, 세계 지도 배경, 창 테두리 9칸, 조수 한별 초상.
2. 사용자 판정 뒤 **나머지**: 대륙 6개 질감, 학회 강당 배경, 해저 배경·줄무늬 질감, 커서.
3. 대륙은 `pieces/<id>.png` 마스크를 참고 이미지로 넣고, 생성 뒤 같은 마스크로 잘라 윤곽을 지킨다(좌표가 바뀌지 않는다).

| 칸 | 정한 것 |
|---|---|
| 마을 타일 | 16×16. 위에서 비스듬히 내려다본 고전 RPG 형식(형식만 참고, 특정 게임을 닮게 하지 않음). 풀·길·물·나무·벽·지붕·부두·꽃 8종. 이음매가 보이지 않게. 지역마다 땅 색만 바꾼다(코드가 색을 곱함). |
