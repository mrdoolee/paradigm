# 대륙이동설 마무리 다듬기 계획 (2026-10-30)

사용자 승인: 2026-10-30 ("마무리 될 때까지 쭉 진행"). 실행: 메인 세션 직접, 끝에 원고·사료 검토와 플레이 검토 각 1회. push·배포 없음.

## 결정
- 마을 화면 기준(앞으로의 게임에도 적용): 그림은 16×16 타일, 마을은 2배(32px)로 표시, 화면 한 장 = 15×10칸. 지도가 더 크면 카메라가 따라가고 지도 밖은 막는다. 대륙이동설 마을 넷은 15×10 한 화면.
  - 근거: 참고 저장소(awesome-gamedev-agent-skills)의 level-design·camera-systems·create-game-assets·rpg·phaser-core에는 수치가 없다. 고전 휴대기 화면(240×160 = 16px 15×10칸)과 우리 480×360 화면의 2배(240×180)에서 정했다.
- 집은 타일로 그린다(이음매 없는 건물 타일 묶음을 마을마다 다시 생성).
- 과학자 초상은 퍼블릭 도메인이 확인된 사진이 있는 사람만, "원작 아님" 표시.
- 땅다리 그림은 게임 세계지도 도트 스타일, 대륙 윤곽은 마스크 참고.
- 판 경계·지진·화산 지도는 공개 데이터로 코드로 그려 정리 1쪽에 넣는다.
