# NOS 도트 그림

## 왜 이 순서인가
이전 저장소에서 그림 약 50점을 한꺼번에 만든 뒤에야 처음 봤고, 화면별 검사는 다 통과했는데 사용자는 "초상·도트·창이 따로 논다"고 했다. 원인: 기준 없이 시작, 대량부터 제작, 그림끼리 일관성을 보는 사람이 없음. 그래서 **STYLE.md → 견본 → 판정 → 대량**을 지킨다.

## 1. STYLE.md 먼저
`activities/<id>/art/STYLE.md`. 칸을 다 채우기 전엔 생성하지 않는다.

| 칸 | 정할 것 |
|---|---|
| 한 줄 콘셉트 | 화면 인상(예: "1910~60년대 지질학 연구실과 낡은 세계 지도, 양피지와 바다색") |
| 팔레트 | 16색 이내, 색 이름·용도(바탕·잉크·바다·땅·강조·무늬 3종). `art/palette.json`과 같게 |
| 픽셀 밀도 | 가상 화면 480×360 기준 1픽셀 = 1도트. 모든 그림이 같은 밀도(초상만 세밀하면 안 됨) |
| 외곽선 | 있는가, 색, 두께 |
| 빛과 그림자 | 방향, 단계 수 |
| 초상 | 64×64, 구도(흉상 정면 등) |
| UI 창 | 테두리·바탕·글자 색이 팔레트의 어느 색인지 |
| 하지 않는 것 | 그라데이션·반투명·중간색 외곽선, 상업 게임 닮음 |

STYLE.md와 견본은 **사용자에게 보여 주고 확인받는다**(인상은 사용자가 정한다).

## 2. 생성 도구 (OpenAI 이미지 API)
- 도구: `sprite-gen`(aldegad/sprite-gen, Apache-2.0). 기본 설치본은 이전 저장소의 `C:\Users\mrdoo\Documents\nos_game_project\tools\sprite-gen`(가상환경 포함, 커밋 59b2738). 새로 설치하려면 이 저장소 `tools/sprite-gen/`(git 제외)에 `git clone https://github.com/aldegad/sprite-gen` → `python -m venv .venv` → `.venv/Scripts/pip install -e .`. 원본 설명서는 그 폴더의 `SKILL.md`·`docs/`.
- Windows: 실행 파일 `.venv/Scripts/sprite-gen.exe`, 파이썬 `.venv/Scripts/python.exe`. 한국어 출력이 깨지면 `PYTHONIOENCODING=utf-8`.
- 공급자 `--provider openai`. 키는 이 저장소 루트 `.env`의 `OPENAI_API_KEY`(사용자가 넣는다), 모델은 `OPENAI_IMAGE_MODEL`. sprite-gen은 `.env`를 스스로 읽지 않으니 실행할 때 환경 변수로만 넘긴다. **키 값을 명령줄·로그·대화에 쓰지 않는다.** 도구 기본 모델이 다르므로 `--model "$OPENAI_IMAGE_MODEL"`을 꼭 넘긴다.
- 래퍼 스크립트 `scripts/art/gen.py`는 단계 E에서 이전 저장소의 같은 파일을 바탕으로 만든다(호출 수 기록 `tools/art-runs/calls.jsonl`, 마젠타 배경 → 배경 제거 → 격자 복원, `--dry-run`, `--from-raw`). 이전 것과 달리 **결과는 PNG**(Phaser가 바로 읽음), 팔레트 글자 격자로 바꾸지 않는다.
- **호출마다 요금이 든다.** 견본 전에 "몇 장, 호출 몇 번"을 사용자에게 알린다. 그림 하나에 호출 한 번, 크레딧·인증 오류는 다시 보내지 않는다.

## 3. 대륙 (실제 지도 기반, 설계 5절)
1. 퍼블릭 도메인 해안선(예: Natural Earth)을 가상 화면 축척으로 투영해 대륙별 **윤곽 마스크 PNG**(1도트 격자, 흰색=땅)를 만든다. 스크립트로 만들어 같은 입력이면 같은 결과가 나오게 한다.
2. 정답 좌표(판게아 자리)는 공개 복원도를 참고해 **같은 마스크 기준**으로 정한다. 프로토타입은 이 마스크를 단색으로 칠해 쓴다.
3. 생성: 마스크를 참고 이미지로 넣고 "이 윤곽 그대로 도트 땅 질감" 프롬프트로 생성 → 격자 복원 → 팔레트 맞춤 → **마스크로 잘라** 윤곽 밖 픽셀을 지운다. 윤곽은 늘 마스크가 정한다.
4. 무늬 층(화석 띠·빙하 화살표·산맥 선)은 정답 배치에서 이어지도록 마스크 좌표로 그린다(생성 또는 손 그림).

## 4. 견본 → 판정 → 대량
- 견본 한 묶음: 대륙 2개(남아메리카·아프리카) + 세계 지도 배경 + 창 테두리 + 조수 초상.
- 대조 시트: `create-game-assets/scripts/build_preview_sheet.py`(sprite-gen 가상환경 파이썬)로 견본을 한 장에 → 실제 게임 화면 스크린샷(`nos-check --shots`)과 함께 사용자에게 보인다.
- 판정 기준(취향 말고 STYLE.md로): 같은 세계인가(밀도·외곽선·빛·채도·팔레트), 팔레트 밖 색 없음, 창과 그림이 한 톤, 실제 배율에서 읽힘, 대륙이 실제 지도와 닮음. 판정은 `nos-play-reviewer`의 점검표 E절로도 받는다.
- 통과해야 나머지를 만든다. 나머지는 견본을 참고 이미지로 넣는다.

## 4-1. 마을 타일 (RPG 활동 공통 기준)
- 타일 16×16, 마을은 2배 표시, 화면 한 장 15×10칸(CLAUDE.md 마을 기준).
- 땅·길·물·나무·소품은 한 칸 타일. 소품은 그 마을 땅 위에 그린다.
- 건물은 **이음매 없는 건물 타일 6종**(지붕·처마·벽·창 벽·문 벽·둘째 벽)으로 쌓는다. 프롬프트에 "가장자리까지 꽉 찬 타일, 테두리·땅 없음"을 쓰고, 받은 뒤 3×3으로 이어 붙여 이음매를 확인한다(`build-tiles.txt` 틀). 집 한 채를 한 칸에 그린 타일은 반복하면 깨져 보인다.
- 사람·동물은 16×24, 같은 도트 크기(`cut.py --pitch`)로 잘라 동물이 사람만큼 커지지 않게 한다.

## 5. 출처와 금지
- 그림마다 `activities/<id>/art/PROVENANCE.md`: 지도 자료·복원도 출처와 라이선스, 생성 모델·날짜·참고 이미지, 손질 내용.
- 생성 원본·작업 폴더(`tools/art-runs/`)는 git에 넣지 않는다. 게임에 쓰기로 고른 결과만 `activities/<id>/art/`로.
- 실존 인물 초상: 퍼블릭 도메인 초상화·사진(저작권 확인 필수)만 참고 이미지로, "원작 아님" 표시, 희화화 금지. 진본 초상이 없거나 저작권이 불확실하면 그리지 않고 이름표만.
- 포켓몬스터 등 상업 게임의 이름·캐릭터·그림을 프롬프트나 참고 이미지로 쓰지 않는다.
